## 🚀 Key Highlights
- **1-Click Detection**: Instantly detects HTML tables on any page.
- **⚡ Auto-Scroll Virtual Scraper**: Solves dynamic virtual-scroll tables (order books, trading depth, infinite grids).
- **100% Client-Side**: Zero telemetry or server hops. Runs strictly in browser memory.
- **UTF-8 BOM**: Excel opens cleanly without garbled characters or mojibake.
